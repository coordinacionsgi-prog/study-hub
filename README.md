# Study Hub

App de estudio estática (flashcards + quiz) para varias materias, generada a partir de apuntes y clases grabadas.

Materias:
- Control de Gestión
- Manejo de Materiales y Distribución en Planta (Intralogística)

## Desarrollo local

```
npm install
npm run dev
```

## Build

```
npm run build
```

Se publica automáticamente en GitHub Pages vía GitHub Actions al pushear a `main`.
